# EVE 风格桌面端知识星图

## 目标

将首页中心从稀疏的球壳节点改为有前后深度的知识星区。参考 EVE 星图的密集星点、细线网络、克制标注和选中路线，不复制游戏资产或界面。只调整桌面端星图，保留搜索、筛选和知识阅读器。

## 画面与数据

- 17 个真实架构维度形成不规则的三维星区，相关知识节点围绕所属维度分布；中心区域有足够密度，边缘留出暗部。
- 默认显示可探索的架构知识点；原始资料和页码证据仅在现有证据操作中出现。所有可点击的星点均来自 `graph.json`。
- 细线按真实关系绘制。普通连线低亮度，悬停突出相邻关系，选中后沿真实层级链高亮路线，避免展示未经数据支持的因果路径。
- 只有主题、当前悬停和选中链路显示名称，其余星点以大小、亮度和景深表达层级。

## 动态与交互

- 首次进入时镜头在约 1.5 秒内从远处斜视角推进；偏好减少动态效果时立即显示稳定画面。
- 拖拽旋转三维视角，释放后短暂减速；滚轮和现有按钮平滑缩放。缩放时逐步显示更细的知识层。
- 悬停时邻近节点和连线变亮；点击节点时镜头平移并靠近，真实层级路线依次点亮，现有阅读器打开。
- 暂停按钮控制自动缓慢巡航；切到后台时不持续绘制高开销动画。重置按钮回到总览。

## 边界

- 不增加移动端界面或触屏流程。
- 保留 Canvas 路径与现有数据模型，不引入远程依赖；通过确定性三维布局和透视投影实现深度。
- 不用随机装饰点冒充可点击知识节点；装饰星尘始终位于知识网络之后。
